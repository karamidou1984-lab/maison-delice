Maison Délice — حالة التطوير والربط

الفرع الجاري تطويره:
work/maison-delice-completion

الملفات الأساسية:
- index.html: واجهة المتجر ولوحة الإدارة.
- supabase-config.js: عنوان Supabase ومفتاح Publishable العام فقط.
- storefront-enhancements.js: السلة والمفضلة وإرسال الطلب.
- delivery-settings.js: إعداد رسوم التوصيل من لوحة الإدارة.
- supabase/migrations/20261125_secure_store_checkout.sql: ترقية قاعدة البيانات اللازمة للطلبات وصور المنتجات.

ما أصبح موجوداً في الكود:
- عرض المنتجات والتصنيفات.
- سلة مشتريات ومفضلة وبحث.
- نموذج طلب بالدفع عند الاستلام.
- لوحة إدارة للمنتجات والطلبات والعملاء والمخزون.
- تعديل المنتجات وتفعيلها أو إخفاؤها وإضافة رابط صورة HTTPS.
- متابعة حالة الطلب وعرض عناصره.
- إعداد رسوم التوصيل لكل ولاية وبلدية دون أسعار افتراضية.

تنبيه مهم:
- التعديلات محفوظة في فرع التطوير وطلب الدمج رقم 1، ولم تُدمج في main.
- ملف SQL لم يُنفذ في مشروع Supabase بعد.
- لا تفتح استقبال الطلبات قبل تنفيذ ترقية قاعدة البيانات وإضافة رسوم التوصيل الصحيحة.
- لا تضع أي كلمة مرور أو service_role أو secret key داخل ملفات الموقع.
- المفتاح الموجود في supabase-config.js هو Publishable key عام.
- نجاح فحص صياغة JavaScript لا يغني عن اختبار المتجر فعلياً في المتصفح.

قبل النشر:
1. راجع ملف SQL وتأكد من أسماء الجداول والسياسات والدوال في مشروع Supabase.
2. نفّذ الترقية في بيئة مناسبة بعد أخذ نسخة احتياطية، ثم تحقق من إنشاء الدالة والجداول والسياسات.
3. أضف أسعار التوصيل الحقيقية من لوحة الإدارة.
4. اختبر دخول المدير، عرض المنتجات، الصور، السلة، الطلبات، المخزون وتغيير حالة الطلب.
5. انشر النسخة المختبرة على Vercel بعد مراجعة إعدادات المشروع.

لا تعتبر المتجر جاهزاً لاستقبال الزبائن حتى إكمال الاختبارات السابقة.
